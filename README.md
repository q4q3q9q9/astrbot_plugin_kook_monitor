# KOOK 开黑提醒

> 如果你是 AI Agent，或者想看完整文档，请看 [AGENTS.md](AGENTS.md)。

KOOK 语音频道有人进来或离开时，自动发消息到你的群聊或私聊。支持 AstrBot 接入的各种聊天平台（QQ、Telegram、Discord、飞书、钉钉等），已在 OneBot（NapCat）下测试。

## 三步用起来

**1. 创建 KOOK 机器人，拿到 Token**

打开 [KOOK 开发者中心](https://developer.kookapp.cn) → 新建应用 → 左侧「机器人」：
- 连接模式选 **WebSocket**；
- 复制 **Token**；
- 点「邀请链接」，把机器人拉进你的 KOOK 服务器。权限只勾「查看频道」就够了。

**2. 安装并配置插件**

在 AstrBot 中安装本插件，然后到插件的配置页面填入 Token，其他选项按需调整。

**3. 订阅提醒**

在想接收提醒的群里，由管理员发送：

```
/kook_browse
```

机器人会列出它所在的服务器和语音频道，每一行末尾有一个代号：

```
【周末开黑服】全部语音频道 · 1
  双排房 · 1.1
  五排房 · 1.2
```

发送 `/kook_sub 代号` 订阅，例如 `/kook_sub 1.1` 只订阅双排房，`/kook_sub 1` 订阅整台服务器。代号 10 分钟内有效，群里任何人浏览出的列表都可以用，过期了重新 `/kook_browse`。

想省事的话，直接发 `/kook_sub` 就是订阅所有服务器的全部语音频道。

最后在群里发 `/kook_test`，确认机器人能在这个群里发消息。

## 常用指令

按使用顺序排列：

| 指令 | 作用 |
|---|---|
| `/kook_browse` | 列出可订阅的服务器和语音频道 |
| `/kook_sub 代号` | 订阅代号对应的服务器或频道（可多次追加） |
| `/kook_sub` | 订阅全部服务器的语音频道 |
| `/kook_list` | 查看当前订阅了什么 |
| `/kook_test` | 检查插件状态（Token、连接、订阅等），并往当前群或私聊发一条测试消息预览提醒文案 |
| `/kook_unsub` | 取消订阅。订阅了多项时会列出序号，再发 `/kook_unsub 序号` 退订其中一项 |
| `/kook_help` | 显示命令菜单（也可以发 `/kook help`） |

- 在群里发是给这个群订阅，私聊机器人发是给你自己订阅。
- 已订阅整台服务器时，再订阅其中的频道不会重复添加；改订整台服务器时，原来的单个频道订阅会自动合并。
- **私聊订阅默认关闭**，只有 AstrBot 管理员能私聊订阅。想让朋友们各自私聊收提醒，请在插件配置里打开「允许普通用户私聊订阅」。

## 可以改的设置

在插件配置页面里：

- **进入 / 离开提醒的文案**：可以使用 `{user}` 昵称、`{guild}` 服务器名、`{channel}` 频道名、`{time}` 时间。
- **离开提醒延迟**：默认 120 秒。离开后 2 分钟内又回到同一个频道，就不提醒，避免掉线重连时刷屏。
- **只提醒进入 / 只提醒离开**：分别有开关。
- **群订阅仅限管理员**：默认开启。
- **允许普通用户私聊订阅**：默认关闭，只有管理员能私聊订阅。

## 常见问题

**收不到提醒？**
- 先发 `/kook_test`，自检报告会指出 Token、连接、订阅哪里有问题。
- 检查机器人是否已经在 KOOK 服务器里。
- 检查该语音频道是否禁止了机器人查看。
- 私聊订阅时，大多数平台要求你先和机器人聊过天（QQ 需要先加好友）。

**Token 泄露了怎么办？**
在 KOOK 开发者中心重置 Token，再把新 Token 填回插件配置。
